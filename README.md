# Arjuna Gustrinator — Developer Portfolio

Personal portfolio website showcasing my work across **Mobile App Development (Flutter)**, **Full-Stack Web & Backend Systems (PHP/Laravel, NestJS, Next.js, PostgreSQL)**, and **AI Agents & Automation (LangGraph, Node.js, Python)**.

## Featured Projects

- **AttendFlow** — Employee GPS attendance platform (Flutter Android app, Next.js + Leaflet web admin, NestJS + Prisma + PostgreSQL REST API).
- **Kafka WhatsApp Bot** — WhatsApp AI assistant powered by Node.js (Baileys) and LangGraph with 47 guarded tools, multi-format document export (PDF/DOCX/PPTX/XLSX), and Python evaluation suites.
- **Aruma Coffee** — Interactive specialty coffee landing page crafted with Tailwind CSS and GSAP animations.

## Tech Stack

- HTML5 (semantic markup & accessible controls)
- CSS3 (custom properties, responsive CSS Grid/Flexbox, reduced-motion support)
- Vanilla JavaScript (scroll spy, interactive stack console, project filtering, case study modal)

> Originally started from Dimas Abimanyu's HTML/CSS tutorial foundation and redesigned into a custom portfolio.
